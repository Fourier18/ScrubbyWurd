Import a list

    
A list has one item per line: the text to find, then what to replace it with. Two kinds of file work:

    

      

        Text file (.txt)
        Made in Notepad. Press the Tab key between the two parts.
        
John Smith⇥ TabMark Jones
Acme Corp⇥ Tab[company]

      

      

        Spreadsheet (.csv)
        Made in Excel or Google Sheets. Find in column A, replacement in column B. Save as CSV UTF-8.
        
AB
1John SmithMark Jones
2Acme Corp[company]

      

    

    

      
      
    

    
    
    

    

      
      
      
    

  





  

    
Export your list

    
Save your list to a file so you can load it again later with Import, on this computer or another one.

    

      
      
      
    

    
The list holds the original names you're hiding. Keep the file somewhere private.

    
If you edit the .csv in Excel, it can turn phone numbers, long ID numbers and dates into a different format. Check those items after you import the list again.
