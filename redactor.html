Import a list

    
A list has one item per line: the text to find, then what to replace it with. Two kinds of file work:

    

      

        Text file (.txt)
        Made in Notepad. Press the Tab key between the two parts.
        
John Smith⇥ TabMark Jones
Acme Corp⇥ Tab[company]

      

      

        Spreadsheet (.csv)
        Made in Excel or Google Sheets. Find in column A, replacement in column B. Save as CSV UTF-8.
        
AB
1John SmithMark Jones
2Acme Corp[company]
